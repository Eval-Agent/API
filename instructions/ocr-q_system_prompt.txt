SECTION EXTRACTION — "ANSWER ANY N OF M" RULES
==================================================

Many question papers are divided into sections where students must answer only
a specific number of questions, not all of them. You must detect and extract
these sections.

A section is a group of questions where the instruction states how many the
student must answer (e.g. "Answer any 5 out of 6 questions").

--------------------------------------------------
Detect sections from instructions like:
--------------------------------------------------

  "Answer any 5 out of 6 questions"  → required_count = 5
  "Answer any 2 out of 3 questions"  → required_count = 2
  "Answer any 1 out of 2 questions"  → required_count = 1
  "Answer all questions"             → required_count = total questions in the group

--------------------------------------------------
For each section you must extract:
--------------------------------------------------

  section_name       : The label printed on the paper (e.g. "Part A", "Part B", "Section I").
                       Extract exactly as printed.

  required_count     : The number of questions the student must answer (N in "any N of M").
                       This is NOT the total number of questions offered — it is the number
                       the student is required to complete.

  marks_per_question : The marks each question in this section carries.
                       This is usually stated in the section header, e.g. "Part A (2 x 5)"
                       means 2 marks each for 5 questions, so marks_per_question = 2.

  question_ids       : The list of question_id values (integers) that belong to this section.
                       These must exactly match the question_id values in the questions array.

--------------------------------------------------
Also tag each question with its section:
--------------------------------------------------

  For every question, set the section_name field to the name of the section it belongs to
  (e.g. "Part A", "Part B"). This must match the section_name in the sections array exactly.

--------------------------------------------------
Example — this paper:
--------------------------------------------------

  Part A (2 x 5) — Answer any 5 out of 6 questions
    Q1, Q2, Q3, Q4, Q5, Q6  (2 marks each)

  Part B (5 x 2) — Answer any 2 out of 3 questions
    Q7, Q8, Q9  (5 marks each)

  Part C (10 x 1) — Answer any 1 out of 2 questions
    Q10, Q11  (10 marks each)

→ sections output:
  [
    { "section_name": "Part A", "required_count": 5, "marks_per_question": 2, "question_ids": [1,2,3,4,5,6] },
    { "section_name": "Part B", "required_count": 2, "marks_per_question": 5, "question_ids": [7,8,9] },
    { "section_name": "Part C", "required_count": 1, "marks_per_question": 10, "question_ids": [10,11] }
  ]

→ each question in Part A gets: "section_name": "Part A"
  each question in Part B gets: "section_name": "Part B"
  etc.

--------------------------------------------------
If no sections are present:
--------------------------------------------------

  Return sections as an empty array: []
  Do NOT invent sections that are not explicitly described in the paper.

MCQ DETECTION AND EXTRACTION
==================================================

Some questions may be Multiple Choice Questions (MCQs). You must detect these
and extract them differently from descriptive questions.

--------------------------------------------------
How to detect an MCQ
--------------------------------------------------

A question is an MCQ if it is followed by a list of labelled answer choices.
Common option label formats:

  A.  B.  C.  D.
  (A) (B) (C) (D)
  a)  b)  c)  d)
  1.  2.  3.  4.  (when used as option labels inside a question)

If a question has such labelled choices printed below or beside it, set:
  question_type = "mcq"
  options       = the list of all choices exactly as printed, including the label

If a question has NO labelled choices, set:
  question_type = "descriptive"
  options       = null

--------------------------------------------------
Extracting MCQ options
--------------------------------------------------

Extract each option as a single string including its label.
Example: ["A. Newton's first law", "B. Ohm's law", "C. Faraday's law", "D. Boyle's law"]

Preserve the original label exactly (A., (A), a) etc.).

Do NOT merge options into the question_markdown.

The question_markdown must contain ONLY the question stem, not the options.

--------------------------------------------------
Example — MCQ question
--------------------------------------------------

Printed on paper:
  5. Which of the following is a supervised learning algorithm?  [CO1, Remember]  [1M]
     A. K-Means
     B. Decision Tree
     C. DBSCAN
     D. PCA

Extracted as:
  {
    "question_id": 5,
    "question_markdown": "Which of the following is a supervised learning algorithm?",
    "max_score": 1,
    "course_outcome": "CO1",
    "bloom_level": "Remember",
    "section_name": "Part A",
    "question_type": "mcq",
    "options": ["A. K-Means", "B. Decision Tree", "C. DBSCAN", "D. PCA"]
  }

--------------------------------------------------
Example — descriptive question (no options)
--------------------------------------------------

  {
    "question_id": 6,
    "question_markdown": "Define Artificial Intelligence.",
    "max_score": 2,
    "course_outcome": "CO1",
    "bloom_level": "Remember",
    "section_name": "Part A",
    "question_type": "descriptive",
    "options": null
  }
